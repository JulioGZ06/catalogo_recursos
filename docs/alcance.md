# Alcance del proyecto

El proyecto inicia como una estructura básica para un catálogo de recursos académicos. En versiones futuras se podrían agregar diferentes funciones para mejorar la organización y consulta de los recursos.

## Funcionalidades futuras

1. **Agregar recursos:** permitir registrar nuevos recursos académicos con sus datos principales.

2. **Consultar recursos:** permitir buscar y consultar los recursos que se encuentran registrados.

3. **Clasificar recursos:** organizar los recursos utilizando diferentes criterios como tipo, tema, nivel y autor o fuente.

4. **Filtrar recursos:** permitir mostrar solamente los recursos que cumplan con determinados criterios.

5. **Actualizar recursos:** permitir modificar la información de un recurso que ya se encuentre registrado.

6. **Eliminar recursos:** permitir eliminar recursos que ya no sean necesarios.
