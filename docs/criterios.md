# Criterios para clasificar recursos

Los recursos académicos pueden clasificarse utilizando diferentes criterios para facilitar su organización y búsqueda.

## 1. Tipo

Permite identificar qué tipo de recurso es. Por ejemplo:

* Libro
* Artículo
* Video
* Página web
* Documento

## 2. Tema

Indica el tema principal relacionado con el recurso. Por ejemplo:

* Programación
* Matemáticas
* Estructura de datos
* Electrónica

## 3. Nivel

Indica el nivel académico para el que está dirigido el recurso. Por ejemplo:

* Básico
* Intermedio
* Avanzado

## 4. Autor o fuente

Permite identificar quién creó el recurso o de dónde proviene. Puede ser una persona, institución, universidad o plataforma educativa.
